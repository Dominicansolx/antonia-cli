Este proyecto es un pequeño homenaje a su sabiduría y su cariño infinito.

---

### ¿Qué es Antonia CLI?

Antonia CLI es un agente de código IA **gratis** y fácil de usar, creado especialmente para desarrolladores dominicanos y latinos.

Está basado en **Aider** y funciona con modelos locales (como Ollama + llama3.2). Te permite editar archivos, usar git, ejecutar comandos y recibir ayuda mientras programas, todo desde la terminal.

---

### Cómo usar (forma más fácil)

1. Descarga o clona el repositorio.
2. Abre la carpeta en la terminal.
3. Ejecuta el launcher haciendo **doble clic** en `run_antonia.bat`

¡Listo! Verás el mensaje de bienvenida de Doña Antonia y se abrirá el asistente.
