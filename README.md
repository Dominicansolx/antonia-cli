### ¿Qué es Antonia CLI?

Antonia CLI es un **agente de código IA gratuito** y fácil de usar, creado especialmente para desarrolladores dominicanos y latinos.

Está basado en **Aider** y funciona con modelos locales (como Ollama + Llama 3.2). Te permite editar archivos, trabajar con git, ejecutar comandos y recibir ayuda mientras programas, todo desde la terminal.

---

### Cómo usarlo (la forma más fácil)

1. Descarga o clona este repositorio.
2. Abre la carpeta `AntoniaCLI`.
3. Haz **doble clic** en el archivo `run_antonia.bat`.

¡Listo! Verás el mensaje de bienvenida de Doña Antonia y se abrirá el asistente de código.
