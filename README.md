### ¿Qué es Antonia CLI?

Antonia CLI es un agente de código IA **gratis** y fácil de usar, creado especialmente para desarrolladores dominicanos y latinos.  

Está basado en Aider y te permite:
- Editar archivos
- Ejecutar comandos
- Trabajar con git
- Recibir ayuda mientras programas

Todo desde la terminal, con soporte para modelos locales (como Ollama).
